# Задание агенту для лабораторной работы 5

Пользователь поручил выполнить лабораторную работу по приложенной методичке и предоставил сайт и отчёт из лабораторной работы 4.

На основе методички агент сформулировал следующий план изменений. Это рабочее техническое задание, а не дословная цитата отдельного пользовательского сообщения.

1. Сохранить исходный сайт «Кофейный котик» коммитом в main.
2. В ветке feature/photos добавить не менее трёх локальных фотографий. Заменить иллюстрации первого экрана и истории фотографиями, добавить галерею с тремя изображениями, ссылками на источники и доступными подписями.
3. Сохранить тёплую палитру, меню из шести напитков, фильтры, бонусные правила и мобильную навигацию.
4. Объединить feature/photos с main отдельным merge-коммитом.
5. Создать feature/project-docs для документации и подготовки публикации GitHub Pages, затем объединить с main.
6. Проверить фотографии, фильтры, навигацию и отсутствие горизонтального переполнения.

Отдельные скриншоты пользовательского чата не создавались и не имитировались. Публикация, форк и удалённые ветви требуют подтверждения фактического результата на GitHub.
