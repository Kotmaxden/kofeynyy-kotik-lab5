# Кофейный котик

Учебный лендинг кофейни. Лабораторная работа 5 по информатике: организация репозитория в Git.

## Содержимое

- `index.html`: адаптивный сайт, стили и скрипт.
- `assets/images/`: три фотографии JPEG, список источников и JSON-манифест.
- `TASKS.md`: постановка задачи агенту и фактически выполненные изменения.
- `CHANGELOG.md`: описание двух этапов разработки.
- `.nojekyll`: публикация статических файлов через GitHub Pages.

## Ветки

- `main`: итоговая версия.
- `feature/photos`: три фотографии, галерея и навигация к ней.
- `feature/project-docs`: документация и подготовка к GitHub Pages.

Обе рабочие ветки объединены в main отдельными merge-коммитами с двумя родителями. Ветки сохранены для проверки истории.

## Локальный просмотр

Откройте `index.html` в браузере или используйте Live Server. Все изображения находятся в проекте; внешние библиотеки не требуются.

## Данные и изображения

Сайт является учебной концепцией. История, меню, цены, акции и адрес демонстрационные. График: 08:00-22:00. Фотографии взяты из свободных источников, а не сняты автором лабораторной. См. [источники](assets/images/CREDITS.md).
